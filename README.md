C++ Programming Project
8.2 - SPELL CHECK
Utility that scans user text, removes punctuation, checks it against a Unix words list and flags unrecognized words.
8.7 - CIPHER
Keyword based cipher that encrypts or decrypts file content based on user-selected operation and input word.

Both projects are meant to show competency in beginning C++ programming concepts, including console input/output, mathematical functions,
string processing, dynamic sequence containers, file input/output and character classification. All work presented in this repository is my own.
